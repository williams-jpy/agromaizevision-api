# 🌽 AgroMaizeVision API

FastAPI backend for AgroMaizeVision.

The API receives maize leaf images, processes them using a machine learning model, and returns disease predictions.

## Features

- REST API
- Image upload
- Machine learning inference
- JSON responses
- FastAPI

## Tech Stack

- Python
- FastAPI
- Machine Learning
- Uvicorn
